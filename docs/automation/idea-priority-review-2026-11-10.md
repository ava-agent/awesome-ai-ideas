## 1. Agent Security ReviewOps

[原条目 · #1472](../../ideas/issue-1472--for-Agent-Developers-CTOs-Agent-Security-ReviewOps--AI-Agent-Runtime-Security-and-Permission-Governance-Platform.md)

- **排名与变化**　保留第一。小团队的 Agent 开发者和技术负责人需要查清工具能读写哪些数据、数据会流向哪里。上线前权限审查可以用隔离环境和固定样本复现，启动所需依赖最少。
- **验证**　1–2 周内离线回放五个脱敏仓库接入任务，预标注正常读写、越权写入和模拟外发。对照工具调用记录与权限清单。
- **验收或暂缓**　全部预置高风险动作均被标记，审查者能定位到调用及规则，正常路径仍能完成。拿不到隔离回放环境则暂缓，漏报预置风险则停止扩大试点。
- **建议角色与产物**　平台工程师和安全评审者，交付回放脚本、权限清单、JSON 审计日志及一页结果。

## 2. MeetingTrack AI

[原提案 · #1512](../../prs/1512-MeetingTrack-AI.md)

- **排名与变化**　新列第二。工程经理或产品经理需要把会议决定落实到责任人和截止日期。提案中的行动项提取可独立验证，能先用合成或获准脱敏的逐字稿，较事故复盘更容易建立样本。
- **验证**　1–2 周内用五份逐字稿做盲测，覆盖明确承诺、待定建议、缺责任人和缺日期。输出带原文引用的行动项清单，记录手工整理与审阅清单各自用时。预先由评审者标注事实，接入和提醒留待验证通过后评估。
- **验收或放弃**　明确行动项的召回率至少 80%，所有责任人和日期均可回溯到原文，未知字段留空，复核时间中位数低于手工整理。若编造承诺或复核没有节省时间，暂缓平台化。合成样本通过后再用授权材料验证真实工作流。
- **建议角色与产物**　产品工程师和工程经理或产品经理，交付文本输入原型、标注对照表和计时记录。

## 3. Healthcare Admin Precision Copilot

[原条目 · #1460](../../ideas/issue-1460--for-Care-Coordinators-Medical-Scribes-Healthcare-Admin-Precision-Copilot--From-Manual-Administrative-Drudge-to-AI-Powered-Clinical-Administrative-Workflow-Ecosystem.md)

- **排名与变化**　保留第三，等待领域复核和样本。专科诊所的行政人员需要在事前授权提交前查齐 payer 字段和附件。核对清单可独立试验，规则和样本获取决定能否启动。
- **验证**　条件齐备后，用 1–2 周回放单专科、单 payer 的五份合成或获准脱敏案例，由领域人员盲审必填项缺口和附件索引。
- **验收或暂缓**　全部预置的必填项缺失均可定位到规则和材料，人工准备时间中位数低于手工核查。缺领域复核者、可用规则或授权样本则暂缓。产物仅供人工提交前检查。
- **建议角色与产物**　诊所行政领域评审者和工程师，交付字段对照、缺项清单及附件索引样例。
